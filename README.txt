CARA PAKAI TEMPLATE
1. Buka folder clothing-brand-template.
2. Buka index.html dengan Chrome untuk melihat website.
3. Ganti nama NOVAWEAR dengan nama brand pelanggan.
4. Ganti harga dan nama produk langsung di index.html.
5. Masukkan foto pelanggan ke folder images dengan nama:
   hero.jpg
   about.jpg
   product-1.jpg
   product-2.jpg
   product-3.jpg
   product-4.jpg
6. Untuk WhatsApp, ganti 6281234567890 dengan nomor WhatsApp pelanggan (format internasional, tanpa +).
7. Setelah selesai, folder tersebut bisa dikirim/dijual kepada pelanggan.
